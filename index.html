The filters show up.

A large HVAC company's techs run this app in the field. It opens already knowing who they are — company account, crew, van, order limit — so there is no login friction at the top of a ladder. The whole flow is built for busy hands: speak the order, tap one big card for the job site, hear the total read back, and confirm the delivery with the code from a text message. Nothing in the flow requires typing.

  1. Say it. “Two cases of 20 by 25 by 1, MERV 8 — and one case of 16 by 20 by 4, MERV 13.” The app transcribes it, parses it into order lines, and checks stock at both distribution centers.
  2. Point at the job. Job-site delivery, specifically: saved site cards, a delivery window, spoken drop-off notes.
  3. Hear it back. The review screen reads the order and the full estimated cost out loud — items, delivery, tax — before anything is committed.
  4. Lock it by text. Placing the order sends a text with the ETA, the total, and a 6-digit code. The code goes in on a glove-sized keypad and the delivery is locked.

Demo data only. Every person, company, site, price, and stock count on this page is invented, and no order goes anywhere. Where the browser supports it, the mic button uses real speech recognition and the read-back uses real speech synthesis; otherwise the mock speaks a sample order so the flow can still be walked end to end.
